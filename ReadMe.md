StudyTrack

Study Planner

StudyTrack is a simple Python program designed to help students organize their study tasks and track their progress.

🎯 Project Goal

The goal of this project is to make it easier for students to manage study tasks, record study hours, and see their progress.

 How It Works

The program allows the user to:
	•	Add study tasks
	•	Record the subject and study hours
	•	Mark completed tasks
	•	View the study plan
	•	Calculate progress and total study hours

 Technologies
	•	Python
